# NOTE ON PYTORCH (read this if the download looks enormous)
# On Linux, plain `pip install torch` pulls the CUDA build - roughly 2.5 GB -
# even if you have no NVIDIA GPU. Everything in this course is designed to run
# on CPU, so on Linux install the much smaller CPU-only build FIRST:
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#
# then run `pip install -r requirements.txt` as normal.
# On macOS and Windows the default install is already the right one.
