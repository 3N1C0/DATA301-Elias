# DATA 301: Introduction to Machine Learning - Fall 2026
# Packages used across the semester (Day 1-22, exams, final project).
#
# Install once, from inside your repo folder:
#   pip install -r requirements.txt
#
# These install into your regular Anaconda Python, alongside whatever your other
# classes use, so almost nothing here is locked to an exact version. If you
# already have a working numpy or pandas, this leaves it alone.
#
# The three deep learning packages have an upper limit on the major version. Those
# libraries change fast and a new major release can break notebooks mid semester.
# The limits let you get bug fixes without waking up to a breaking change.
#
# ---------------------------------------------------------------------------
# NOTE ON PYTORCH (read this if the download looks enormous)
# On Linux, plain `pip install torch` pulls the CUDA build, roughly 2.5 GB, even
# if you have no NVIDIA GPU. Everything in this course is designed to run on
# CPU, so on Linux install the much smaller CPU-only build FIRST:
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#
# then run `pip install -r requirements.txt` as normal.
# On macOS and Windows the default install is already the right one.
# ---------------------------------------------------------------------------
